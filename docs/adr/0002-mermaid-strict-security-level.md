# Mermaid diagrams render with `securityLevel: 'strict'`

Mermaid diagrams are rendered with `securityLevel: 'strict'`, which HTML-escapes node/edge labels and disables `click` interaction JS execution entirely (no clickable node links). We rejected `'loose'`, which would allow `click A href "..."` node links, because it also permits `javascript:` URIs unless separately filtered — a real XSS vector given that any document (including anonymously-authored public docs) can contain a mermaid block. This is consistent with the existing decision to disable raw HTML passthrough via `rehype-sanitize` (see CLAUDE.md `## Security`): diagrams get the same "no script execution from document content" guarantee as the rest of the preview pipeline. The practical cost is that diagram nodes can never be clickable links, even for trusted/self-authored docs — there's no per-doc opt-in.
